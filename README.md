Kalon Zero is a fast, native terminal for the Mac. Workspaces with tabs and splits, a sidebar that shows what your coding agents are doing, a built-in browser and the Kalon assistant, all in one window.

## Requirements

macOS 14 Sonoma or later, on a Mac with Apple silicon.

## Install

1. Download [Kalon-Zero.dmg](https://github.com/KalonEdge/kalon-zero/releases/latest/download/Kalon-Zero.dmg).
2. Open it and drag Kalon Zero into Applications.
3. Open Kalon Zero from your Applications folder.

Kalon Zero and its disk image are signed by its developer and notarized by Apple, so macOS checks both before anything opens.

## Updates

Kalon Zero keeps itself up to date. It checks for a new version once a day, downloads it in the background and installs it when you quit, so it never interrupts a running program. To check right away, choose Kalon Zero › Check for Updates…. Automatic updates can be turned off in Settings › General.

An update is installed only after Kalon Zero confirms it matches the release and carries its developer's signature.

Every version is listed, with what changed, on the [Releases](https://github.com/KalonEdge/kalon-zero/releases) page.

## Privacy

Kalon Zero runs on your Mac. Passwords and keys in your terminal output are hidden before anything is shared with the assistant or saved to disk, and the assistant uses the Kalon app on your Mac unless you choose another server. Checking for updates sends only an ordinary request for the latest version.
