# Security

If you believe you've found a security issue in Kalon Zero, please report it privately rather than in public, through [kalonedge.com/contact](https://kalonedge.com/contact).

Please include the version of Kalon Zero (Kalon Zero › About Kalon Zero), your version of macOS, and the steps that show the issue.

## Supported versions

Security fixes go into the latest release. Kalon Zero installs updates by itself, so keeping automatic updates on (Settings › General) keeps you protected.
